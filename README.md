## Структура проєкту

- `integrators.py` — модуль з ієрархією класів чисельного інтегрування.
- `main.py` — головний файл запуску програми.

## Постановка задачі

Обчислити визначений інтеграл

$$I = \int_0^1 \cos(x + x^3)\,dx$$

із точністю $\varepsilon = 10^{-4}$

## Інструкція запуску

```bash
python main.py
```

## Результати обчислень

| Метод інтегрування | $\varepsilon = 10^{-4}$ ($n_{\min}$) | Уточнене значення ($\varepsilon = 10^{-4}$) |
| :--- | :---: | :---: |
| **Формула прямокутників** | 64 | 0.6334461 |
| **Формула трапецій** | 64 | 0.6334461 |
| **Формула Сімпсона** | 8 | 0.6334643 |

## Висновки

Усі три методи дали близькі значення інтеграла. 
Метод Сімпсона досяг потрібної точності при $n_{\min} = 8$, 
тоді як методам прямокутників і трапецій знадобилося по 64 розбиття.
